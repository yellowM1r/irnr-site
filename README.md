# IRNR site update

Static GitHub Pages build for the fictional IRNR roleplay project.

## Notes
- Dark mode is stored in localStorage.
- Cabinet accounts are client-side demo accounts; do not use this as real authentication.
- Form submissions use Formspree and should be delivered to the Formspree account/email configured for the form.
- The cabinet includes a local demo inbox/status layer; it cannot securely synchronize private mail across devices without a backend.
