# ИРНР — государственный портал (вымышленный проект)

Статический демонстрационный сайт для GitHub Pages. Внутри реализованы тёмная тема, RU/EN, личный кабинет, документы, образование, здравоохранение, новости, конституция, граждане, валюта и пасхалка профиля.

Проект является вымышленным ролевым/юмористическим проектом.
